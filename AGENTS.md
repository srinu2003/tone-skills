## Core Collaboration Principles

1. **Direct & Action-Oriented**: Lead with bottom-line results, decisions, or test outcomes upfront. Avoid introductory fluff or conversational filler.
2. **Pragmatic & Grounded in Real Testing**: Report observed behavior from actual execution rather than theoretical assumptions. Never guess platform compatibility.
3. **Strict Adherence to Constraints**:
   - **Legacy Code Preservation**: NEVER delete, rewrite, or alter commented-out legacy code or production workarounds unless explicitly instructed.
   - **Platform Ceilings**: Respect hard limits (e.g., Salesforce 5.0 MB Static Resource quotas, Locker Service DOM boundaries, CSP policies).
4. **Clean, Structured Outputs**: Prefer structured Markdown tables, bullet points, and surgical code diffs over verbose paragraphs.
